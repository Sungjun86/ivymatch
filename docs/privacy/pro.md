# IvyMatch Pro 개인정보처리방침

시행일: **2026년 11월 3일**

**JAMESKO**(이하 "개발자")이 제공하는 Android 유료 앱 **IvyMatch Pro**(패키지 이름 `com.sungjun86.ivymatch.pro`, 이하 "앱")의 개인정보 처리에 관한 안내입니다.

## 1. 한눈에 보기

- 이 앱은 **광고가 없습니다.**
- 개발자는 **서버를 운영하지 않고, 회원가입·로그인이 없으며, 개인정보를 수집하지 않습니다.**
- 앱을 쓰며 입력하거나 선택한 내용(입학 연도 선택, SAT·ACT 점수)은 **기기 밖으로 전송되지 않습니다.**

## 2. 앱이 다루는 정보

| 구분 | 내용 |
|---|---|
| 개발자가 수집하는 개인정보 | **없음** |
| 기기 안에만 저장되는 값 | 선택한 **입학 연도**(2027~2030 중 하나) |
| 저장하지 않는 값 | 입력한 SAT·ACT 점수, 검색어, 필터 선택 (화면이 열려 있는 동안만 기기 메모리에 있음) |
| 개발자 서버 또는 제3자로 전송되는 정보 | **없음** |

기기 안의 저장값은 앱을 삭제하면 함께 지워집니다.

## 3. 포함된 소프트웨어 (제3자 SDK) 안내

이 앱에는 **광고 SDK, 분석 SDK 등 이용자 정보를 수집하는 제3자 소프트웨어가 포함되어 있지 않습니다.** 무료판(IvyMatch)에 들어 있는 Google Mobile Ads SDK는 유료판 빌드에서 제외되어 있으며, 앱은 네트워크로 이용자 정보를 보내지 않습니다.

> 같은 앱의 무료판은 광고를 위해 Google이 광고 ID 등을 수집합니다. 무료판의 방침은 별도 문서로 제공됩니다.

## 4. 외부 사이트 연결

학교 상세 페이지의 "입학처 열기" 버튼과 출처 링크를 누르면 **기기의 웹 브라우저로 해당 학교 사이트가 열립니다.** 그 사이트의 개인정보 처리는 각 사이트의 방침을 따르며 개발자는 관여하지 않습니다.

## 5. 결제

앱 구입(₩2,000)은 **Google Play**를 통해 이루어지며 결제 정보는 Google이 처리합니다. 개발자는 카드번호 등 결제 정보를 받지 않습니다. 환불은 Google Play의 환불 정책에 따릅니다.

## 6. 아동의 개인정보

앱은 **만 16세 이상** 이용자를 대상으로 하며, **어린이를 대상으로 한 앱이 아닙니다.** 개발자는 개인정보를 수집하지 않으므로 아동의 정보도 수집하지 않습니다.

## 7. 보유 기간과 파기

개발자는 개인정보를 수집·보유하지 않으므로 별도의 보유 기간이나 파기 절차가 없습니다. 기기 안의 저장값은 앱 삭제 시 파기됩니다.

## 8. 제3자 제공·처리 위탁

개발자는 이용자의 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.
